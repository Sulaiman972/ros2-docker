Docker container for ROS2. This is only personal documentation.

Install packages with these commands:

```
sudo apt upgrade && sudo apt update
sudo apt install ros-jazzy-desktop && sudo apt install ros-jazzy-ros-base
sudo apt-get install ros-jazzy-rviz2 ros-jazzy-turtle-tf2-py ros-jazzy-tf2-ros ros-jazzy-tf2-tools ros-jazzy-turtlesim
```
